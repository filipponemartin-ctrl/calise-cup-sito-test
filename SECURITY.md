# Sicurezza

Se trovate un problema di sicurezza nel tema, non aprite una segnalazione pubblica.

- Usate **Security → Report a vulnerability** in questo repository, oppure
- scrivete a calisecup@gmail.com con oggetto "Sicurezza sito".

Indicate cosa avete trovato e come riprodurlo. Vi rispondiamo appena possibile.

È supportata solo l'ultima versione pubblicata.
